# Оформление панели

В **Сервер → Настройки панели → Оформление панели** можно задать название
(1–80 символов) и выбрать стандартный логотип, свой файл или режим без логотипа.
Настройки общие для всех устройств: применяются к экрану входа, меню, названию
вкладки, favicon и имени PWA. Технические названия Telemt в диагностике остаются.
Оформление не скрывает тип приложения от технического анализа.

Для своего логотипа укажите **абсолютный путь на сервере**, например
`/var/lib/telemt-panel/logo.webp`. Поддерживаются PNG, WebP и JPEG до 5 МиБ,
4096 пикселей по каждой стороне и 8 миллионов пикселей суммарно. Файл должен
читаться пользователем службы панели; права root и sudo для чтения не используются.
Для Docker укажите путь **внутри контейнера** и подключите файл или каталог
через volume, желательно read-only.

Браузер получает изображение от самой панели, без внешних запросов. Путь к файлу
доступен только администратору. Не размещайте конфиги и другие приватные данные
в изображении или его метаданных: логотип намеренно общедоступен на экране входа.

Сохранение проверяет и загружает файл в память, после чего применяет оформление
без перезапуска. При ошибке сохраняется предыдущее оформление. После замены
изображения по прежнему пути **сохраните настройки повторно**, чтобы перечитать
файл. Если после перезапуска файл недоступен, название остаётся вашим, а логотип
скрывается; в настройках появляется предупреждение.

Название, режим и путь хранятся в `panel-state.json` независимо от выбранного
драйвера истории. В резервную копию включайте и сам файл изображения: его содержимое
в state-файл не записывается. При `data_dir = ""` настройки временные.

«Вернуть стандартное» заполняет форму исходными значениями; для применения
нажмите «Сохранить оформление». Уже установленная PWA может сохранять старую
иконку или имя в кеше операционной системы — для обновления иногда требуется
удалить ярлык и установить PWA заново.
